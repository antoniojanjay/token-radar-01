Token Radar ranks pre-token protocols by implied value, estimated from live-token market-cap/TVL multiples with growth and maturity adjustments. It ships a sortable dashboard with per-protocol detail, farm plans and a model sandbox.

## Run it

```sh
node main.ts
```

Pass `--input <snapshot.json>` to score a snapshot locally; the grader runs it against the sealed snapshot. Requires Node.js 22.18 or later.
